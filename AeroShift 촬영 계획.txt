# AeroShift 촬영 계획

1. 게임 시작 화면 촬영
2. 스킨 선택 화면 진입
3. 기본 비행기가 선택되어 있는지 확인
4. 화살표 버튼을 눌러 스킨이 변경되는지 확인
5. Back 버튼을 눌렀다가 다시 스킨 선택 화면에 진입했을 때 기본 비행기로 돌아오는지 확인
6. 다른 비행기로 변경한 후 Select 버튼을 눌러 선택이 적용되는지 확인
7. Start 버튼을 눌러 Regular Map과 Random Map 선택 화면이 나타나는지 확인
8. Regular Map 먼저 선택
9. 스킬 선택 화면 확인
10. Reroll 버튼을 눌러 재추첨이 한 번만 가능한지, 스킬 선택지가 변경되는지 확인
11. 스킬을 선택한 후 실제 게임에서 정상적으로 작동하는지 확인 (**모든 스킬 개별 촬영**)
12. 비행기 스킨별 기능이 정상적으로 적용되는지 확인 (**모든 스킨 촬영**)
13. 장애물에 충돌한 후 Restart 버튼을 눌러 게임이 초기화되는지 확인
14. 재시작 시 스킬 선택 화면이 다시 나타나는지 확인
15. 스킬을 선택한 후 장애물에 충돌
16. Back 버튼을 눌러 처음 화면으로 돌아가는지 확인
17. Start 버튼을 다시 눌러 Random Map 선택
18. 스킬 선택 화면에서 스킬 선택
19. 장애물이 무작위로 배치된 맵이 생성되는지 확인
20. 점수 2배 효과가 정상적으로 적용되는지 확인
