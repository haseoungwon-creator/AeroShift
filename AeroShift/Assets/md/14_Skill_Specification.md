# 14. 스킬 시스템 명세

**상태:** [원본 스킬 명세 보존 + AeroShift 연계 항목 계획] · **기준:** 업로드된 `aeroflip_skill_specification.md`

## 1. 공통 규칙

- 액티브: 1회 사용. 즉발형·일정 지속형·횟수형(보호막처럼 충돌 1회 소모)으로 나뉜다.
- 패시브: 선택 시점부터 매치 종료까지 적용.
- 2D 전용 / 3D 전용 / 공용을 구분한다.
- **Transition 중 액티브 스킬 사용 불가.**
- 상대 대상 스킬은 상대의 차원과 상태 조건을 검증한다. 조건 불일치·전환 중이면 사용 횟수를 소모하지 않는다.
- 상대 대상 스킬 요청을 검증하는 주체는 네트워크 구조 확정 후 정의한다. PUN2 마스터 클라이언트와 권위 서버는 구분한다.

## 2. 2D 전용 액티브 스킬

| 이름 | 영문 | 대상 | 모드 | 효과 |
|---|---|---|---|---|
| 미사일 억제 | Missile Suppression | 자신 | 멀티 | 일정 시간 미사일 생성 개수 감소 |
| 미사일 감속 | Missile Slow | 자신 | 멀티 | 현재 및 신규 미사일 속도 일시 감소 |

## 3. 3D 전용 액티브 스킬

| 이름 | 영문 | 대상 | 모드 | 효과 |
|---|---|---|---|---|
| 시간 역행 | Time Rewind | 자신 | 싱글/멀티 | 직전 몇 초의 기체·맵 진행·장애물 상태 복원 |
| 시간 감속 | Slow Motion | 자신 | 싱글/멀티 | 자신의 월드 진행/장애물 속도 감소; 자신 기체·상대에게는 영향 없음 |
| 위상 대시 | Dash / Blink | 자신 | 멀티 | 전방 순간 이동 및 짧은 무적 |
| 충격파 발사 | Shockwave | 자신 | 멀티 | 전방 장애물 파괴 |
| 시야 차단 | Dimension Fog | 상대(3D) | 멀티 | 3D인 상대의 전방 시야에 안개 표시 |

> 원본 스킬 명세에서 시간 감속 설명에 2D 미사일이 언급되지만, 게임 기획 v2는 이 스킬을 3D 전용으로 분류한다. **현행 게임 규칙은 3D 전용을 우선 적용**하며 2D 영향은 미정 사항으로 보류한다.

## 4. 공용 액티브 스킬

| 이름 | 영문 | 대상 | 모드 | 효과 |
|---|---|---|---|---|
| 위상 보호막 | Phase Shield | 자신 | 멀티 | 다음 1회 충돌 무효화 |
| 중력 반전 | Gravity Flip | 상대 | 멀티 | 일시적으로 상대 조향 방향 반전 |

## 5. 멀티플레이 패시브

| 이름 | 영문 | 효과 |
|---|---|---|
| 점수 증폭 | Score Catalyst | 기본/콤보 점수 배율 증가 |
| 이동 속도 증가 | Speed Boost | 월드 진행(또는 기체 비행) 속도 증가 |
| 이동 속도 감소 | Speed Dampener | 속도 감소, 조작 여유 증가 |
| 조향 민감도 증가 | High Sensitivity | 반응 속도 증가 |
| 조향 민감도 감소 | Low Sensitivity | 반응 속도 감소 |

## 6. 스킬 선택

원본 기획서의 멀티 방식: 매치 시작 시 랜덤 카드 3장을 제시, 제한 시간 안에 선택하고 미선택 시 자동 선정. 양 플레이어에게 서로 다른 카드 풀이 제공될 수 있다. **싱글의 스킬 선택 방식은 원본에서 미정**으로 남아 있다. 신규 구상 '액티브 1 + 패시브 2'는 별도 밸런스 확정 전에는 제안으로 표시한다.

## 7. 시간 역행 상세 규칙

1. 사용 후 스냅샷에서 과거 위치와 월드 진행을 복원한다.
2. **점수는 역행하지 않는다**. 역행 중 점수 증가를 정지한다.
3. 동일 장애물의 Near Miss 보상을 두 번 주지 않는다.
4. 멀티 상대 화면에는 역행한 고스트 위치를 부드럽게 표현하도록 보간 정책을 둔다.

## 8. 기술 연결

| 스킬 | 연계 기술 |
|---|---|
| 시간 역행 | Circular Buffer, 결정적 청크 생성, ID 기반 이벤트 중복 방지 |
| 시간 감속 | WorldSpeed(원본) 또는 WorldProgressSpeed(대안), 로컬 시뮬레이션 속도 분리 |
| 미사일 억제/감속 | MissileSpawner, MissileSimulation |
| 충격파 | 장애물 활성 상태 변경 및 원상 복구 정책 |
| 상대 디버프 | 차원 상태 네트워크 검증, 스킬 요청 중복 방지 |

## 9. 확정이 필요한 항목

정확한 지속 시간/감속 배율/대시 거리, 스킬 사용 키, 멀티 선택 시간, 싱글 슬롯 구조, 스킬 카드 출현 비율, 시간 감속의 월드/미사일 적용 경계.

## 면접 질문

- 스킬 사용 조건과 효과 실행을 분리해야 하는 이유는 무엇인가요?
- 상대방이 조건에 맞지 않아 발동 실패했을 때 사용 횟수를 돌려주는 방식과 아예 소모하지 않는 방식의 차이는 무엇인가요?
- 시간 역행 이후 점수를 유지하면서 Near Miss 중복 획득을 막는 방법은 무엇인가요?
