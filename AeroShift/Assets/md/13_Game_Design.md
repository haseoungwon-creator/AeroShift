# 13. AeroShift 게임 기획서

**상태:** [AeroFlip v2 기반 개정 기획] · **플랫폼:** PC · **엔진:** Unity 6

## 1. 한 문장 소개

3D 비행 구간과 2D 탑뷰 미사일 회피 구간을 `Shift`로 번갈아 플레이하며 생존하고 점수를 획득하는 아케이드 비행 게임이다.

## 2. 핵심 재미

1. **회피:** 정면의 장애물을 보고 X/Y 방향으로 기체를 조향한다.
2. **차원 전환:** 고속 비행과 사방 미사일 회피 사이에서 전환 시점을 결정한다.
3. **위험 보상:** Near Miss 및 콤보로 점수 상승을 노린다.
4. **기록 경쟁:** 싱글 최고 기록과 1대1 고스트 레이스.

## 3. 게임 흐름

```text
Login → Main Menu
        ├── Single → Ready → Playing → GameOver → Result
        └── Multi → Matchmaking → SkillSelect → Ready → Playing → Result
```

`Playing`의 하위 상태는 `Playing3D / Transition / Playing2D`를 구분한다. 재시작은 가능한 한 한 씬에서 상태를 초기화하는 방식으로 설계한다.

## 4. 3D 구간

- 마우스로 비행기를 조향하고 기체가 롤/피치로 기울어지는 연출.
- 맵에는 바위, 벽, 좁은 통로 등의 고정 장애물이 등장하며 **3D 미사일은 등장하지 않는다**.
- 시작은 안전 맵, 진행할수록 다양한 구간을 연속 제공.
- 좌우·상하 이동 한계는 ScriptableObject 설정값을 따른다.
- 장시간 생존 및 근접 회피가 점수의 중심이다.

## 5. 2D 구간

- 시점은 **탑뷰**. WASD로 화면 내 평면 이동.
- 미사일이 상/하/좌/우 4방향에서 경고 후 발사된다.
- 일반 패턴은 랜덤 생성 간격, 개수, 방향·위치 조합으로 확장 가능.
- 2D에서 3D로 복귀하기 전 **4방향 각 5발, 총 20발의 고정 패턴**을 진행한다.

## 6. 차원 전환

| 전환 | 플레이 순서 |
|---|---|
| 3D→2D | Shift → 안전 맵 준비 → 안전 구간 도착 → 상승 연출 → 2D 시작 |
| 2D→3D | Shift → 일반 스폰 중지 → 20발 전환 패턴 → 하강 연출 → 3D 시작 |

전환 중 중복 입력·액티브 스킬을 차단한다. 점수는 연출 중 정지했다가 완료 후 재개한다. AeroShift에서는 기존 카메라 이동 방식 외에 차원별 2D/3D 물리·입력·렌더 표현을 나누는 설계를 **추가 계획**한다.

## 7. 게임오버와 결과

- 기본적으로 장애물/미사일에 충돌하면 즉시 해당 주행 종료.
- 보호막 등 충돌 1회 무효 스킬이 있다면 예외 처리.
- 결과 화면에서 점수, 생존 시간, Near Miss, 최고 기록, 재시작을 제공한다.
- 계정 최고 기록 저장은 계획 사항이며, 저장 제공 서비스는 아직 최종 확정 전이다.

## 8. 싱글플레이

끝없이 진행하는 기록 도전 모드. 시간 역행·시간 감속 등의 스킬을 선택할 수 있는 방향으로 검토한다. **원본 v2는 싱글 스킬 선택 방식을 미정**으로 남겨 두었으며, 이후 제안인 액티브 1개 + 패시브 2개 구조는 확정 구현 규칙으로 쓰기 전에 별도 검증이 필요하다.

## 9. 멀티플레이

- 1대1, 같은 Seed로 같은 맵 패턴을 경험.
- 상대는 충돌하지 않는 반투명 고스트로 표시.
- 두 플레이어의 차원과 월드 진행은 독립적.
- 매치 초반 랜덤 카드 3장 중 스킬 선택, 미선택 시 자동 선택(원본 기획).
- 경기 시간·충돌 후 처리·점수 비교 규칙 세부 수치는 **미정**.

## 10. 스킨

원본 v2는 **스킨이 외형과 능력치를 함께 바꾼다**고 규정한다. 능력치는 이동 속도(또는 월드 진행 속도), 조향 민감도, 점수 배율. 능력치는 `ScriptableObject`로 관리하고 조합 상한을 둔다. 경쟁 공정성을 위해 외형 전용 규칙을 별도로 채택할지는 추후 결정한다.

## 11. 계정과 저장

저장 후보: 계정 식별 정보, 최고 점수, 보유/선택 스킨, 설정. PlayFab은 후보 서비스이며 점수 검증 및 부정행위 대응 방안은 별도 설계 대상이다.

## 변경 관리와 미정 항목

### 확정된 최신 변경

- 프로젝트 이름: `AeroShift` (기존 문서명 AeroFlip을 계승).
- **LOD 사용 제외**, 화면 밖 렌더링 관리 검증으로 변경.
- 물리·입력·표현이 다른 2D/3D 전환 아키텍처 설계 추가.
- 최적화 포트폴리오를 위해 ProfilerRecorder/CSV 및 Job/Burst 실험을 계획.

### 원본과 최신 논의의 차이 — 최종 구현 확인 필요

| 항목 | 원본 첨부 문서 | 이후 논의 | 상태 |
|---|---|---|---|
| 전진 표현 | 월드가 뒤로 이동, 기체 X/Y 제한 | 기체가 Z 방향으로 실제 이동하는 방식 검토 | **최종 채택 확인 필요** |
| 싱글 스킬 선택 | 방식 미정 | 액티브 1개 + 패시브 2개 구상 | **수치/규칙 확인 필요** |
| 점수 | 생존 시간 틱 + Near Miss + 콤보 | 거리 점수 병행 구상 | **점수 가중치 미정** |
| 멀티 종료 | 원본 미정 | 시간 종료 후 점수 비교 방향 | **충돌 시 처리 미정** |

### 수치 미정

전환 대기 시간·쿨다운·연출 길이, 미사일 속도·빈도, 스킬 지속 시간, 단위 시간 점수량, 스킨 보정 수치, 매치 시간, 싱글 스킬 슬롯 구성.
