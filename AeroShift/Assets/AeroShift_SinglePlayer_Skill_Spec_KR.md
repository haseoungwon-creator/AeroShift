# AeroShift / AeroFlip 싱글플레이 스킬 시스템 명세서 v2

> **적용 범위: 싱글플레이 전용.** 기존 14종에서 다른 플레이어에게 사용하는 스킬 2종(시야 차단, 중력 반전)을 제외한 **12종**입니다. 기존 멀티 전용이던 자기 강화 스킬은 싱글플레이에서 사용할 수 있도록 변경했습니다. JSON과 본 명세서는 동일한 v2 구성입니다. 수치는 실제 밸런스 테스트 전의 **초기 제안값**이며, **게임 코드에는 아직 연결되지 않았습니다.**

## 1. 이번 변경 사항

| 변경 항목 | 결과 |
|---|---|
| 전체 스킬 | 14종 → **12종** |
| 제거한 상대 대상 스킬 | **시야 차단(Dimension Fog)**, **중력 반전(Gravity Flip)** |
| 기존 멀티 전용 자기 대상 스킬 | **모두 싱글플레이 사용 가능**으로 전환 |
| 상대 조건·서버 검증 | JSON에서 상대 차원 검증·서버 권한 검증 등의 규칙 제거 |
| 선택 화면 | 시작 전 **3개 무작위 카드 → 1개 선택** |
| 적용 파일 | `AeroShift_SinglePlayer_SkillBalance_v2.json` |

이 변경은 스킬 *설정 및 기획*의 수정입니다. 실제 효과 구현과 UI 연결, 성능 검증은 별도 개발이 필요합니다.

## 2. 공통 게임 규칙

1. **게임 시작 전 선택:** 로딩 완료 후 `SkillSelection` 상태에서 12종 중 중복 없이 3개를 제시하고, 1개를 고른 뒤 `Playing`에 진입합니다. 한 판에서 **선택 가능한 스킬은 1개**입니다.
2. **액티브 스킬:** 사용 가능한 차원에서 성공적으로 발동하면 **해당 판에서 1회 소모**됩니다. 시간 지속형은 지정된 초 동안 유지하고, 즉시형은 발동 즉시 처리합니다.
3. **패시브 스킬:** 카드 선택이 확정되면 활성화하며, 해당 판 종료 때까지 유지합니다. 3D 전용 패시브는 2D에 머무는 동안 효과만 일시 중단합니다.
4. **차원 제한:** 2D 전용 액티브는 2D에서만, 3D 전용 액티브는 3D에서만 사용합니다. 공용 액티브는 양쪽에서 사용 가능합니다. **3D↔2D 전환 연출 중에는 모든 액티브 사용을 막습니다.**
5. **실패 시 횟수 보존:** 차원 조건 미충족, 유효한 되감기 기록 없음, 안전하지 않은 대시 목적지 등으로 실제 효과가 시작되지 않았다면 횟수를 소비하지 않습니다. 발동 성공 후 미적중한 충격파는 이미 소비된 것으로 봅니다.
6. **차원 이탈 시 처리:** 2D/3D 전용 시간 지속형 액티브 효과는 해당 차원을 떠날 때 조기 종료합니다. 위상 보호막은 한 번 발동한 후 차원 전환을 거쳐도 유지됩니다.
7. **시간 계측:** 타임 슬로우와 충돌하지 않도록 **게임 진행 시계(일시정지/스킬 선택 중에는 정지)** 기준으로 지속 시간을 셉니다. `Time.timeScale`을 변경해 전체 게임을 일괄 감속하는 것은 권장하지 않습니다.
8. **한 판 종료 및 재시작:** 적용 배율, 보호막, 일시적 무적, 사용 횟수, UI 상태를 초기화합니다. 기본 FlightConfig/ScriptableObject 값을 직접 변경하지 않습니다.

## 4. 스킬별 세부 능력치와 구현 규칙

### 4.1 2D 전용 액티브 (2종)

#### 미사일 억제 (Missile Suppression)

- **JSON ID:** `missile_suppression` · **유형:** 2D 전용 액티브 · **발동 차원:** 2D · **효과 차원:** 2D · **사용 횟수:** 1회/판 · **효과 종료:** 6초
- **효과:** 2D 미사일 생성량을 일정 시간 줄여 회피 공간을 확보하는 스킬.

| 효과 (`effectId`) | 수치 항목 (`key`) | JSON 값 |
|---|---|---:|
| 미사일 생성 수 (`MissileSpawnCountMultiplier`) | 효과 배율 (`multiplier`) | `0.45` |
| 미사일 생성 수 (`MissileSpawnCountMultiplier`) | 웨이브당 최소 생성 수 (`minimumMissilesPerWave`) | `1` |

- **계산/동작 예시:** 한 웨이브에 10발이었다면 ceil(10 × 0.45) = 5발. 1발 미만은 허용하지 않음.
- **구현 시 연결할 시스템:** 2D 미사일 웨이브 생성 수를 계산하는 지점에 배율을 적용. 스킬 사용 이전에 발사된 미사일에는 영향 없음.
- **실패·종료 처리:** 2D가 아니거나 차원 전환 중일 때 사용 불가. 2D를 떠나거나 6초 경과 시 해제.

#### 미사일 감속 (Missile Slow)

- **JSON ID:** `missile_slow` · **유형:** 2D 전용 액티브 · **발동 차원:** 2D · **효과 차원:** 2D · **사용 횟수:** 1회/판 · **효과 종료:** 5초
- **효과:** 화면에 존재하는 미사일과 새로 발사되는 미사일의 이동 속도를 낮추는 스킬.

| 효과 (`effectId`) | 수치 항목 (`key`) | JSON 값 |
|---|---|---:|
| 미사일 속도 (`MissileSpeedMultiplier`) | 효과 배율 (`multiplier`) | `0.6` |
| 미사일 속도 (`MissileSpeedMultiplier`) | 기존 미사일에도 적용 (1=예) (`applyToExisting`) | `1` |
| 미사일 속도 (`MissileSpeedMultiplier`) | 신규 미사일에도 적용 (1=예) (`applyToNew`) | `1` |

- **계산/동작 예시:** 원래 20m/s로 이동하던 미사일 → 20 × 0.60 = 12m/s(40% 감속).
- **구현 시 연결할 시스템:** 미사일 기본 속도와 적용 중인 효과 배율을 분리. Pool에 반환되는 미사일의 속도 배율도 초기화.
- **실패·종료 처리:** 2D 외 발동 불가. 2D 이탈 또는 5초 경과 시 효과를 제거하고 기본 속도로 복원.

### 4.2 3D 전용 액티브 (4종)

#### 시간 역행 (Time Rewind)

- **JSON ID:** `time_rewind` · **유형:** 3D 전용 액티브 · **발동 차원:** 3D · **효과 차원:** 3D · **사용 횟수:** 1회/판 · **효과 종료:** 즉시 발동
- **효과:** 최근 플레이 기록에서 3초 전 플레이어 및 월드 위치·회전을 복원하는 즉시형 스킬.

| 효과 (`effectId`) | 수치 항목 (`key`) | JSON 값 |
|---|---|---:|
| 시간 역행 (`RewindHistory`) | 되감기 시간 (초) (`seconds`) | `3` |
| 시간 역행 (`RewindHistory`) | 최소 필요 기록 (초) (`minimumValidHistorySeconds`) | `3` |
| 시간 역행 (`RewindHistory`) | 플레이어 위치·회전 복원 (1=예) (`restorePlayerTransform`) | `1` |
| 시간 역행 (`RewindHistory`) | 월드 위치·회전 복원 (1=예) (`restoreWorldTransform`) | `1` |
| 시간 역행 (`RewindHistory`) | 체력 복원 (1=예) (`restoreHp`) | `0` |

- **계산/동작 예시:** 최소 3초 유효 기록 확보 후 발동. 체력·점수·이미 소비한 스킬 횟수는 복구하지 않음.
- **구현 시 연결할 시스템:** 기존 Circular Buffer의 플레이어와 월드 기록을 같은 타임스탬프 기준으로 복구. 맵/충돌 상태와의 일관성 확인 필요.
- **실패·종료 처리:** 기록이 3초 미만이거나 안전한 복원 상태를 확보하지 못하면 발동 실패로 처리하고 횟수 보존.

#### 시간 감속 (Slow Motion)

- **JSON ID:** `slow_motion` · **유형:** 3D 전용 액티브 · **발동 차원:** 3D · **효과 차원:** 3D · **사용 횟수:** 1회/판 · **효과 종료:** 5초
- **효과:** 비행기 조작 반응은 유지하면서 월드 진행과 관련 미사일의 속도를 각각 줄이는 스킬.

| 효과 (`effectId`) | 수치 항목 (`key`) | JSON 값 |
|---|---|---:|
| 월드 전진 속도 (`WorldForwardSpeedMultiplier`) | 효과 배율 (`multiplier`) | `0.6` |
| 월드 전진 속도 (`WorldForwardSpeedMultiplier`) | 사용자 기체 조작 제외 (1=예) (`excludeCaster`) | `1` |
| 미사일 속도 (`MissileSpeedMultiplier`) | 효과 배율 (`multiplier`) | `0.65` |
| 미사일 속도 (`MissileSpeedMultiplier`) | 기존 미사일에도 적용 (1=예) (`applyToExisting`) | `1` |
| 미사일 속도 (`MissileSpeedMultiplier`) | 신규 미사일에도 적용 (1=예) (`applyToNew`) | `1` |

- **계산/동작 예시:** 월드 20m/s → 12m/s, 미사일 20m/s → 13m/s. 지속 시간은 5초.
- **구현 시 연결할 시스템:** 게임 전체 Time.timeScale을 일괄 수정하기보다 WorldMovement와 Missile의 속도 계산에 배율을 적용.
- **실패·종료 처리:** 3D 외 발동 불가. 3D 이탈 또는 5초 경과 시 각각의 배율을 복원.

#### 위상 대시 (Dash / Blink)

- **JSON ID:** `phase_dash` · **유형:** 3D 전용 액티브 · **발동 차원:** 3D · **효과 차원:** 3D · **사용 횟수:** 1회/판 · **효과 종료:** 즉시 발동
- **효과:** 3D에서 전방으로 최대 8m 순간 이동하고 0.6초간 충돌 피해를 무시하는 스킬.

| 효과 (`effectId`) | 수치 항목 (`key`) | JSON 값 |
|---|---|---:|
| 순간 이동 (`BlinkForward`) | 전방 이동 거리 (m) (`distanceMeters`) | `8` |
| 순간 이동 (`BlinkForward`) | 안전한 목적지 필요 (1=예) (`requireSafeDestination`) | `1` |
| 짧은 무적 (`Invulnerability`) | 장애물 보호 (1=예) (`againstObstacle`) | `1` |
| 짧은 무적 (`Invulnerability`) | 미사일 보호 (1=예) (`againstMissile`) | `1` |
| 짧은 무적 | 해당 효과만 별도 지속 시간 | `0.6초` |

- **계산/동작 예시:** 최대 이동 거리 8m, 짧은 무적 0.6초. 장애물/미사일 충돌 피해 보호.
- **구현 시 연결할 시스템:** AeroShift가 플레이어를 고정하고 월드를 이동시키는 구조이므로, 화면상 전방 이동을 어떤 좌표계로 구현할지 결정한 뒤 안전 지점을 검사해야 함.
- **실패·종료 처리:** 안전한 목적지가 없거나 전환 중이라면 횟수를 차감하지 않음. 무적은 0.6초 후 제거.

#### 충격파 발사 (Shockwave)

- **JSON ID:** `shockwave` · **유형:** 3D 전용 액티브 · **발동 차원:** 3D · **효과 차원:** 3D · **사용 횟수:** 1회/판 · **효과 종료:** 즉시 발동
- **효과:** 3D 전방으로 충격파를 발사해 파괴 가능으로 지정된 장애물을 제거하는 스킬.

| 효과 (`effectId`) | 수치 항목 (`key`) | JSON 값 |
|---|---|---:|
| 충격파 (`LaunchShockwave`) | 사거리 (m) (`rangeMeters`) | `24` |
| 충격파 (`LaunchShockwave`) | 판정 반경 (m) (`radiusMeters`) | `3.5` |
| 충격파 (`LaunchShockwave`) | 속도 (m/s) (`speedMetersPerSecond`) | `30` |
| 충격파 (`LaunchShockwave`) | 파괴 가능 장애물만 (1=예) (`destructibleOnly`) | `1` |

- **계산/동작 예시:** 사거리 24m, 판정 반경 3.5m, 투사체 속도 30m/s. 최대 거리까지 단순 이동 시간 약 0.8초.
- **구현 시 연결할 시스템:** 파괴 가능 태그/컴포넌트만 대상으로 판정. 풀링 오브젝트는 Destroy보다 반환 경로 사용. 지형과 맵의 필수 Collider는 파괴하지 않음.
- **실패·종료 처리:** 3D 외 발동 불가. 탄 발사 자체가 성공하면 횟수 소모, 적중하지 않았더라도 환불하지 않음.

### 4.3 2D·3D 공용 액티브 (1종)

#### 위상 보호막 (Phase Shield)

- **JSON ID:** `phase_shield` · **유형:** 2D·3D 공용 액티브 · **발동 차원:** 2D/3D · **효과 차원:** 2D/3D · **사용 횟수:** 1회/판 · **효과 종료:** 다음 충돌 1회 또는 게임 종료
- **효과:** 2D와 3D 어디서나 발동할 수 있는 1회 충돌 방어 스킬.

| 효과 (`effectId`) | 수치 항목 (`key`) | JSON 값 |
|---|---|---:|
| 충돌 1회 보호 (`AbsorbNextHit`) | 방어 가능 충돌 횟수 (`hitCount`) | `1` |
| 충돌 1회 보호 (`AbsorbNextHit`) | 장애물 보호 (1=예) (`againstObstacle`) | `1` |
| 충돌 1회 보호 (`AbsorbNextHit`) | 미사일 보호 (1=예) (`againstMissile`) | `1` |

- **계산/동작 예시:** 피격 판정 1회 무효화. 시간이 정해져 있지 않으며, 한 번 막거나 게임이 끝나면 해제.
- **구현 시 연결할 시스템:** 동일 프레임에 OnTrigger/OnCollision이 여러 번 들어오는 경우를 대비해 최초 유효 피격 1회만 소비하도록 처리.
- **실패·종료 처리:** 차원 전환 중에는 발동 불가. 발동 전 실패 시 횟수 보존. 발동 후 사용 횟수 소모.

### 4.4 패시브 (5종)

#### 점수 증폭 (Score Catalyst)

- **JSON ID:** `score_catalyst` · **유형:** 패시브 · **발동 차원:** 선택 즉시 · **효과 차원:** 2D/3D · **사용 횟수:** 선택 즉시 적용 · **효과 종료:** 게임 종료까지
- **효과:** 게임 종료까지 기본 점수와 콤보 점수 획득량을 모두 늘리는 패시브.

| 효과 (`effectId`) | 수치 항목 (`key`) | JSON 값 |
|---|---|---:|
| 점수 배율 (`ScoreMultiplier`) | 기본 점수 배율 (`baseScoreMultiplier`) | `1.25` |
| 점수 배율 (`ScoreMultiplier`) | 콤보 점수 배율 (`comboScoreMultiplier`) | `1.25` |

- **계산/동작 예시:** 기본 100점 → 125점, 콤보 추가 40점 → 50점(각각 ×1.25, 반올림 규칙은 구현 시 확정).
- **구현 시 연결할 시스템:** ScoreManager의 점수 계산 단계에 단일 배율 적용. UI 표시 값만 바꾸지 말고 실제 누적 점수에 반영.
- **실패·종료 처리:** 선택 즉시 활성화. 게임 종료 또는 재시작 초기화 시 효과 제거.

#### 이동 속도 증가 (Speed Boost)

- **JSON ID:** `speed_boost` · **유형:** 패시브 · **발동 차원:** 선택 즉시 · **효과 차원:** 3D · **사용 횟수:** 선택 즉시 적용 · **효과 종료:** 게임 종료까지
- **효과:** 3D 월드 전진 속도를 게임 종료까지 15% 높이는 위험·보상형 패시브.

| 효과 (`effectId`) | 수치 항목 (`key`) | JSON 값 |
|---|---|---:|
| 월드 전진 속도 (`WorldForwardSpeedMultiplier`) | 효과 배율 (`multiplier`) | `1.15` |

- **계산/동작 예시:** 기본 20m/s → 23m/s.
- **구현 시 연결할 시스템:** WorldMovement의 기본 진행 속도에 ×1.15. 2D 모드에는 적용하지 않음. 난도 상승과의 합산/곱연산 순서는 고정해야 함.
- **실패·종료 처리:** 2D에서는 일시 비활성, 3D 복귀 시 다시 활성. 게임 종료 시 해제.

#### 이동 속도 감소 (Speed Dampener)

- **JSON ID:** `speed_dampener` · **유형:** 패시브 · **발동 차원:** 선택 즉시 · **효과 차원:** 3D · **사용 횟수:** 선택 즉시 적용 · **효과 종료:** 게임 종료까지
- **효과:** 3D 월드 전진 속도를 게임 종료까지 15% 낮춰 조작 여유를 주는 패시브.

| 효과 (`effectId`) | 수치 항목 (`key`) | JSON 값 |
|---|---|---:|
| 월드 전진 속도 (`WorldForwardSpeedMultiplier`) | 효과 배율 (`multiplier`) | `0.85` |

- **계산/동작 예시:** 기본 20m/s → 17m/s.
- **구현 시 연결할 시스템:** WorldMovement의 기본 진행 속도에 ×0.85. 점수/진행 속도와의 밸런스 트레이드오프를 테스트해야 함.
- **실패·종료 처리:** 2D에서는 효과를 일시 정지하고 3D 복귀 시 재적용. 게임 종료 시 해제.

#### 조향 민감도 증가 (High Sensitivity)

- **JSON ID:** `high_sensitivity` · **유형:** 패시브 · **발동 차원:** 선택 즉시 · **효과 차원:** 3D · **사용 횟수:** 선택 즉시 적용 · **효과 종료:** 게임 종료까지
- **효과:** 3D 기체 조향 반응을 20% 높여 빠르게 방향을 바꿀 수 있게 하는 패시브.

| 효과 (`effectId`) | 수치 항목 (`key`) | JSON 값 |
|---|---|---:|
| 조향 반응 (`AircraftSteeringResponseMultiplier`) | 효과 배율 (`multiplier`) | `1.2` |

- **계산/동작 예시:** 조향 응답 계수 4.0 → 4.8 (×1.20).
- **구현 시 연결할 시스템:** 기존 FlightConfig의 수치를 런타임에 직접 덮어쓰지 않고, 기본값 × 패시브 배율로 최종 조향 계수를 계산.
- **실패·종료 처리:** 2D WASD 이동에는 적용하지 않음. 3D에서만 적용하고 게임 종료 시 해제.

#### 조향 민감도 감소 (Low Sensitivity)

- **JSON ID:** `low_sensitivity` · **유형:** 패시브 · **발동 차원:** 선택 즉시 · **효과 차원:** 3D · **사용 횟수:** 선택 즉시 적용 · **효과 종료:** 게임 종료까지
- **효과:** 3D 기체 조향 반응을 20% 낮춰 부드럽고 안정적인 조작을 제공하는 패시브.

| 효과 (`effectId`) | 수치 항목 (`key`) | JSON 값 |
|---|---|---:|
| 조향 반응 (`AircraftSteeringResponseMultiplier`) | 효과 배율 (`multiplier`) | `0.8` |

- **계산/동작 예시:** 조향 응답 계수 4.0 → 3.2 (×0.80).
- **구현 시 연결할 시스템:** 조향 민감도를 런타임 계산으로 조절하며 기준값은 유지. 모델 회전과 실제 이동 반응의 차이는 플레이 테스트로 확인.
- **실패·종료 처리:** 2D WASD 이동에는 적용하지 않음. 게임 종료 시 설정 초기화.

## 5. JSON 데이터 구조와 Unity 연동 계획

- JSON 파일: `AeroShift_SinglePlayer_SkillBalance_v2.json` (`schemaVersion: 2`, `gameMode: SinglePlayer`).
- `skills[]` 각 요소: 고유 `id`, UI 이름, `kind`, `casterDimensions`, `effectDimensions`, `usesPerRun`, `durationSeconds`, `endCondition`, `iconId`, `effects[]`.
- 각 효과의 `parameters[]`는 `{ "key": "multiplier", "value": 0.6 }`처럼 **문자열 키 + 숫자 값**으로 저장합니다. Unity `JsonUtility`용 직렬화 클래스에서 배열로 읽을 수 있습니다.
- 기존 v1 스키마의 `eligibleMatchModes`, `targetType`, `targetDimensions`, `usesPerMatch`, 상대 검증·멀티 서버 규칙은 v2에서 제거하거나 `usesPerRun`으로 교체했습니다. **v1 로더를 이미 만들어 두었다면 v2 DTO에 맞게 수정해야 합니다.**
- 아이콘·프리팹·사운드·VFX는 JSON에 직접 참조하지 않고, `id`/`iconId`로 Unity 에셋 카탈로그(`ScriptableObject` 또는 직렬화 매핑)에서 찾습니다.

**권장 실행 흐름:** `MainMenu` → `Loading` → `GameState.SkillSelection` → `SkillSelectionManager`가 3개 카드 제시 → 1개 확정 → `SkillManager`에 스킬 등록 → `Playing` 시작.

**데이터와 실행 로직의 역할 분리**

| 역할 | 담당 |
|---|---|
| `SkillConfigLoader` | 시작 시 JSON 읽기, 스키마 및 ID 중복 검증 |
| `SkillSelectionManager` | 중복 없는 카드 3개 추첨·선택 확정 |
| `SkillManager` | 선택 스킬 보관, 차원·상태 검사, 사용 횟수 기록 |
| `SkillEffectController` | 효과 ID를 실제 게임 시스템 동작에 연결 |
| `GameManager` | Ready / SkillSelection / Playing / GameOver 상태 전환 |
| `DimensionTransition` | 전환 상태 이벤트 제공, 전환 중 사용 차단 |
| `WorldMovement` / `MissileSpawner` / `PlayerRewind` / `ScoreManager` | 각 스킬 효과의 구체적 동작 반영 |

- [ ] 3D 전용 스킬은 2D에서 사용 불가하며 횟수가 보존되는지 확인

## 7. 밸런스 조정 시 주의할 점

- 위 수치는 **설계 가설**이며 플레이어 난이도·유효 FPS·미사일 밀도·속도 증가 규칙 등에 따라 조정해야 합니다.
- 시간 감속·속도 감소 패시브는 게임 난도를 낮추므로, 점수 증가 속도나 월드 진행량과의 균형을 확인해야 합니다.
- 점수 증폭과 속도 증가 패시브가 서로 다른 목적을 제공하는지 검증해야 합니다.
- **기존 기획의 1회 액티브 / 상시 패시브 규칙은 유지**하고, 별도의 쿨다운이나 추가 사용 횟수는 이번 버전에 넣지 않았습니다.

## 8. 청강대 면접 예상 질문

**Q1. 싱글플레이에 맞게 스킬 시스템을 어떻게 변경했나요?**

서버나 상대방 차원 검증처럼 필요 없는 기능을 제거하고, 모든 스킬이 플레이어와 자신의 월드에만 영향을 주도록 구성했습니다. 시작 전 카드 3개 중 하나를 선택하고, 차원 조건과 발동 성공 여부만 검증하도록 설계를 단순화했습니다.

**Q2. JSON을 사용하는 이유는 무엇인가요?**

효과 배율, 지속 시간, 사용 조건을 C# 동작 로직에서 분리해 밸런스를 수정하기 쉽게 만들기 위해서입니다. 실제 효과는 C#에서 처리하고, 프리팹이나 아이콘 같은 Unity 오브젝트 참조는 별도 에셋에서 관리합니다.

**Q3. 차원이 맞지 않을 때 스킬 횟수를 소비하지 않는 이유는 무엇인가요?**

사용자의 입력 자체와 실제 효과 적용 성공을 구분하기 때문입니다. 조건 검증 후 효과가 정상 적용되었을 때만 사용 횟수를 차감하여 상태 불일치와 사용 경험 문제를 방지합니다.

**Q4. 패시브 효과를 ScriptableObject 원본 설정에 직접 적용하면 어떤 문제가 있나요?**

런타임에 변경한 값이 기준 설정과 섞여 다음 게임이나 다른 객체에 영향을 줄 수 있습니다. 따라서 기준값을 보존한 채 런타임 배율을 별도로 계산해야 합니다.

**Q5. 스킬이 게임 성능에 주는 영향을 어떻게 검증할 건가요?**

동일 플레이 조건에서 스킬 발동 전후의 CPU 프레임 시간, P95/P99, GC Alloc, Physics 및 렌더링 비용을 비교합니다. 단순 평균 FPS뿐 아니라 스킬 발동 순간의 스파이크도 확인합니다.
