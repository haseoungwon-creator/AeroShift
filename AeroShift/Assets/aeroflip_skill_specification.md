# 🛸 AeroFlip - 스킬 시스템 명세서 (Skill Specification)

## 1. 전역 작동 규칙 (Skill System Rules)

### 1.1 사용 횟수 및 지속 시간
* **액티브 스킬 (Active Skills):** 
  * 1회성 발동형 스킬입니다.
  * 스킬별로 정의된 일정 지속 시간 동안 효과가 유지된 후 종료됩니다.
* **패시브 스킬 (Passive Skills):** 
  * 게임 시작 시 선택(증강)을 완료한 시점부터 해당 게임(매치)이 종료될 때까지 상시 적용됩니다.

### 1.2 차원 제어 및 사용 제한 (Dimension State Verification)
* **2D 전용 스킬:** 플레이어가 2D 차원 상태일 때만 발동할 수 있습니다. (3D 차원 진입 시 사용 불가)
* **3D 전용 스킬:** 플레이어가 3D 차원 상태일 때만 발동할 수 있습니다. (2D 차원 진입 시 사용 불가)
* **공용 스킬 (2D & 3D):** 2D 및 3D 어느 차원에서든 자유롭게 발동 가능합니다.
* **차원 이동 중 (Transition State):** 2D $\leftrightarrow$ 3D 차원 전환 연출이 진행되는 동안에는 모든 액티브 스킬의 발동이 차단됩니다.

### 1.3 상대방 타겟 스킬 (디버프) 예외 처리 규칙
* **차원 조건 검증:** 
  * 상대방 플레이어를 대상으로 하는 디버프 스킬(예: 시야 차단, 중력 반전 등)을 시전할 때, **상대방이 해당 스킬의 발동 조건 차원에 존재하지 않으면 스킬이 발동하지 않습니다.**
* **스킬 보존 및 재사용:** 
  * 조건 미충족으로 발동 실패한 스킬은 **사용한 것으로 처리하지 않으며(소모 0회)**, 조건을 만족하는 상황이 되었을 때 언제든 다시 사용할 수 있도록 스킬 슬롯이 유지됩니다.

## 2. 세부 스킬 명세

### 2.1 2D 전용 액티브 스킬 (2D-Only Active)

| 스킬명 | 영문명 | 대상 | 모드 | 상세 설명 |
| :--- | :--- | :--- | :--- | :--- |
| **미사일 억제** | Missile Suppression | 사용자 | 멀티 | 2D 차원에서 스킬 지속 시간 동안 스폰되는 미사일의 생성 개수를 대폭 줄입니다. |
| **미사일 감속** | Missile Slow | 사용자 | 멀티 | 2D 차원에서 화면 내 및 새로 생성되는 미사일의 비행 속도를 일시적으로 줄입니다. |

### 2.2 3D 전용 액티브 스킬 (3D-Only Active)

| 스킬명 | 영문명 | 대상 | 모드 | 상세 설명 |
| :--- | :--- | :--- | :--- | :--- |
| **시간 역행** | Time Rewind | 사용자 | 싱글 / 멀티 | 직전 몇 초 동안의 플레이어 위치와 상태를 되돌려 충돌 및 위험 상황을 탈출합니다. |
| **시간 감속** | Slow Motion | 사용자 | 싱글 / 멀티 | 나를 제외한 전방 장애물과 미사일, 월드 진행 속도를 느리게 만듭니다. |
| **위상 대시** | Dash / Blink | 사용자 | 멀티 | 전방으로 순간 이동하며 짧은 무적 상태로 장애물 구역을 즉시 돌파합니다. |
| **충격파 발사** | Shockwave | 사용자 | 멀티 | 비행기 전방으로 충격파를 발사하여 진행 방향의 장애물을 즉시 파괴합니다. |
| **시야 차단** | Dimension Fog | 상대방 | 멀티 | 상대방 화면에 짙은 안개를 생성하여 전방 시야를 가립니다. *(※ 상대가 3D 차원에 있을 때만 발동)* |

### 2.3 공용 액티브 스킬 (Universal Active - 2D & 3D)

| 스킬명 | 영문명 | 대상 | 모드 | 상세 설명 |
| :--- | :--- | :--- | :--- | :--- |
| **위상 보호막** | Phase Shield | 사용자 | 멀티 | 2D/3D 구분 없이 장애물 또는 미사일과의 충돌을 1회 무효화합니다. |
| **중력 반전** | Gravity Flip | 상대방 | 멀티 | 상대방의 기체 조향 입력을 반대로 뒤집습니다. *(예: 마우스를 위로 올리면 비행기는 아래로 이동)* |

### 2.4 패시브 스킬 (Passive - 상시 적용)

| 스킬명 | 영문명 | 대상 | 모드 | 상세 설명 |
| :--- | :--- | :--- | :--- | :--- |
| **점수 증폭** | Score Catalyst | 사용자 | 멀티 | 매치 끝까지 획득하는 기본 점수 및 콤보 점수 배율을 증가시킵니다. |
| **이동 속도 증가** | Speed Boost | 사용자 | 멀티 | 매치 끝까지 기체의 기본 비행 속도를 일정 비율 증가시킵니다. |
| **이동 속도 감소** | Speed Dampener | 사용자 | 멀티 | 매치 끝까지 기체의 기본 비행 속도를 줄여 정밀 조작성을 높입니다. |
| **조향 민감도 증가** | High Sensitivity | 사용자 | 멀티 | 매치 끝까지 기체의 방향 전환(회전력) 반응 속도를 높입니다. |
| **조향 민감도 감소** | Low Sensitivity | 사용자 | 멀티 | 매치 끝까지 기체의 방향 전환을 묵직하고 안정적이게 바꿉니다. |
